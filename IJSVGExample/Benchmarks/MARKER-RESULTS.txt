Marker performance, 2026-10-09

Measured with the Debug IJSVG framework on macOS ARM64 and an optimized Objective C benchmark driver.
These are comparative Debug measurements, not Release performance claims.

Changes
  Reuse the resolved source bounds for all marker instances.
  Resolve directions through zero length segments in linear passes.
  Build a local template for each referenced marker and copy its resolved drawing data.
  Keep independent parent links while sharing immutable paths, colors and dash data.
  Retain per instance resolution for gradients, patterns, text, masks, filters and explicit clipping.
  Omit identity mapping containers and unused clipping containers.
  Omit marker groups that have no independent drawing effect.
  Avoid temporary mutable arrays when a copied paint has zero or one child.

Method
  Each value is the median of seven batches after one warmup operation.
  Initialization uses five operations per batch.
  Cold draw uses three operations per batch and invalidates the paint graph before every draw.
  Warm draw uses ten operations per batch and reuses the resolved graph.
  Export uses one operation per batch with IJSVGExporterOptionNone.
  Drawing uses a 512 by 512 RGBA bitmap. Bitmap creation is excluded.
  Solid and context fixtures use 1000 or 4000 vertices with a circle at every vertex.
  The zero4000 fixture repeats the same vertex 4000 times.
  The baseline framework was copied before the first performance change.
  The final sequence ran the optimized framework, the saved baseline, then the optimized framework again.
  The table below uses the final baseline and optimized runs. Earlier results are also retained.

Validation
  All five baseline and optimized RGBA pixel hashes match.
  All 628 tests passed, including 33 Objective C marker tests.
  Marker coverage includes repeated solid artwork, opacity, dash styles, export, context changes,
  gradients, patterns, text, masks, clipping and long zero length runs.
  Two test literal concatenation warnings were fixed with explicit parentheses.
  The marker suite passed again and the Xcode build log and issue navigator report no warnings.
