Method
One process per size. Square destinations at backing scale 1, normal SVG aspect
fitting. Parse and destination allocation excluded. Process-first draw reported
separately; fresh-instance and repeated-instance times are medians of 15 draws.
Their order alternates, but allocation variants were measured in separate runs:
region, union, region again. This is not a statistically robust speed comparison.
Hooks for CI output conversion and inclusive filter timing run after timed draws.
Bitmap interposition remains installed during timings with counting disabled.
Counters cover CGBitmapContextCreate, CGBitmapContextCreateImage and
CIContext createCGImage:fromRect:format:colorSpace:. They do not measure peak
resident memory, every conversion, malloc traffic or private GPU allocations.
Nested filter times overlap and must not be summed.

Review and next optimization targets
The filter graph crops SourceGraphic and primitive output to the declared region.
The allocation change retains union-based scale caps and existing grid snapping.
Nested drawing retains render-depth/supersampling rules. Mask allocation already
uses a bounded grayscale surface. Reduced dimensions can change CPU/Metal/batch
eligibility; broad correctness still needs the requested suites.

The actual sticker has repeated backing chains c (front), h (paper mask), and m
(reverse print). h adds a white alpha-preserving color matrix; m adds a small
linearRGB blur. Source styling also differs, so filter ID or matching path IDs
alone cannot safely identify interchangeable rendered pixels. Existing filter
caches use paint identity; filtered masks deliberately bypass the mask cache.

Five filter source bitmaps, five independently materialized output-cache copies,
and one grayscale mask explain the 11 bitmap requests in this fixture. Inspect
whether standalone, non-atlas outputs can retain owned storage without copying,
with accurate backing-size accounting. Atlas crops still need independent copies
to avoid retaining disproportionately large atlases. This is a candidate, not a
measured optimization; no renderer changes were added during this investigation.

Sharing the completed backing across c/h/m needs proven equivalent resolved source
content, sampling, color space and common filter prefix, with reflection and
branch-specific effects applied afterward. A visible-flap optimization must
propagate input regions through both backing blurs and all flap shadows; preserve
the sampling grid and use fallback for displacement, tiling, convolution and
backdrop-dependent graphs. A generic clip intersection is insufficient.

Nested cache allocation experiment after that passing run
An eligible caching ancestor now suppresses descendant filter cache snapshots
while rendering its source. The state is thread-local and restored in @finally.
An ancestor with background/indirect-image dependencies, disabled caching, or an
output exceeding the per-image cache limit does not suppress its descendants.
No new cross-paint cache is introduced. If the ancestor allocation fails or its
entry is evicted, the next draw rebuilds the nested results rather than retaining
redundant copies. This trades that fallback reuse for lower first-render storage.
