The -svg11 fixtures replace SVG 2 auto-start-reverse with auto plus a separate
reversed start marker, or replace context paint with explicitly coloured markers.
The -expected fixtures use independently positioned ordinary shapes with no markers.
Both original SVG 2 examples and SVG 1.1 equivalents must match these references,
survive export with both option sets, and preserve appearance when copied.
